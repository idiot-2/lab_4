## Детальна документація endpoint-ів

### 1. GET /api/products
**Опис:** Отримати список усіх доступних товарів.

**Метод:** GET  
**URL:** `http://127.0.0.1:5000/api/products`  
**Авторизація:** Не потрібна  
**Тіло запиту:** Відсутнє

**Відповідь (200 OK):**
```json
{
  "status": "success",
  "data": [
    {
      "id": 1,
      "name": "Товар A",
      "price": 9.99
    },
    {
      "id": 2,
      "name": "Товар B",
      "price": 19.99
    }
  ]
}
```

**Відповідь при помилці (500 Внутрішня помилка сервера):**
```json
{
  "status": "error",
  "message": "Помилка підключення до бази даних"
}
```

**Приклад Curl:**
```bash
curl -X GET "http://127.0.0.1:5000/api/products"
```

---

### 2. POST /api/orders
**Опис:** Створити нове замовлення. Потребує email, адреси доставки та кошика покупок.

**Метод:** POST  
**URL:** `http://127.0.0.1:5000/api/orders`  
**Авторизація:** Не потрібна  
**Content-Type:** application/json

**Тіло запиту:**
```json
{
  "email": "user@example.com",
  "address": "вул. Головна, 123, Місто, Країна",
  "cart": [
    {
      "product_id": 1,
      "quantity": 2
    },
    {
      "product_id": 2,
      "quantity": 1
    }
  ]
}
```

**Відповідь (201 Створено):**
```json
{
  "status": "success",
  "message": "Замовлення створено"
}
```

**Відповідь при помилці (400 Неправильний запит — відсутні поля):**
```json
{
  "status": "error",
  "message": "Відсутні обов'язкові поля"
}
```

**Відповідь при помилці (500 Внутрішня помилка сервера):**
```json
{
  "status": "error",
  "message": "Помилка вставки в базу даних"
}
```

**Приклад Curl:**
```bash
curl -X POST "http://127.0.0.1:5000/api/orders" \
  -H "Content-Type: application/json" \
  -d '{"email":"user@example.com","address":"вул. Головна, 123","cart":[{"product_id":1,"quantity":2}]}'
```

### 4. GET /api/orders/:order_id
**Опис:** Отримати деталі конкретного замовлення, включаючи товари.

**Метод:** GET  
**URL:** `http://127.0.0.1:5000/api/orders/{order_id}`  
**Авторизація:** Не потрібна  
**Параметри шляху:**
- `order_id` (число, обов'язково): Числовий ID замовлення

**Відповідь (200 OK):**
```json
{
  "status": "success",
  "order": {
    "id": 1,
    "email": "user@example.com",
    "address": "вул. Головна, 123",
    "status": "очікування"
  },
  "items": [
    {
      "product_id": 1,
      "quantity": 2
    },
    {
      "product_id": 2,
      "quantity": 1
    }
  ]
}
```

**Відповідь при помилці (404 Не знайдено):**
```json
{
  "status": "error",
  "message": "Замовлення не знайдено"
}
```

**Приклад Curl:**
```bash
curl -X GET "http://127.0.0.1:5000/api/orders/1"
```

---

### 5. PUT /api/orders/:order_id
**Опис:** Оновити статус існуючого замовлення.

**Метод:** PUT  
**URL:** `http://127.0.0.1:5000/api/orders/{order_id}`  
**Авторизація:** Не потрібна  
**Content-Type:** application/json  
**Параметри шляху:**
- `order_id` (число, обов'язково): Числовий ID замовлення

**Тіло запиту:**
```json
{
  "status": "відправлено"
}
```

**Прийняті значення статусу:** `очікування`, `обробляється`, `відправлено`, `доставлено`, `скасовано`

**Відповідь (200 OK):**
```json
{
  "status": "success",
  "message": "Статус оновлено"
}
```

**Відповідь при помилці (400 Неправильний запит — відсутній статус):**
```json
{
  "status": "error",
  "message": "Статус обов'язковий"
}
```

**Приклад Curl:**
```bash
curl -X PUT "http://127.0.0.1:5000/api/orders/1" \
  -H "Content-Type: application/json" \
  -d '{"status":"відправлено"}'
```

---

**Відповідь (200 OK):**


**Приклад Curl:**
```bash
curl -X DELETE "http://127.0.0.1:5000/api/orders/1"
```

## Посібник тестування

1. Запустіть додаток (див. [Швидкий старт](#швидкий-старт))
2. Відкрийте у браузері: http://127.0.0.1:5000/apidocs/
3. Натисніть на кожний endpoint → спробуйте → інспектуйте відповідь

### Спосіб 2: Postman
1. Імпортуйте `postman_collection_lab5.json` в Postman
2. Переконайтесь, що додаток запущений на `http://127.0.0.1:5000`
3. Виконуйте запити по порядку:
   - `Отримати товари` (перевірте наявні товари)
   - `Створити замовлення` (запишіть ID замовлення з відповіді або БД)

   - `Отримати замовлення за ID` (перевірте створене)
   - `Оновити статус замовлення` (змініть статус)
   - `Видалити замовлення` (видаліть замовлення)

### Спосіб 3: Curl (командний рядок)
Використовуйте приклади curl, надані в кожному розділі endpoint-ів вище.

## Усунення проблем

### Проблема: "Не можу підключитися до http://127.0.0.1:5000"
**Рішення:**
- Переконайтеся, що додаток запущений: перевірте вивід терміналу "Running on http://127.0.0.1:5000"
- Перевірте налаштування брандмауера: дозвольте Python-процесу або порту 5000
- На Windows запустіть PowerShell як Адміністратор, якщо потрібно

### Проблема: "404 Не знайдено" на /apidocs/
**Рішення:**
- Переконайтесь, що `flasgger` встановлений: `pip install flasgger`
- Перезапустіть додаток після встановлення
- Перевірте, що `/apispec_1.json` доступний (повинен повертати OpenAPI spec)

### Проблема: "422 Необробнений сутність" при створенні замовлення
**Рішення:**
- Переконайтесь, що тіло запиту — коректний JSON
- Перевірте, що присутні всі обов'язкові поля: `email`, `address`, `cart`
- Кошик мав бути непорожнім масивом: `[{"product_id": X, "quantity": Y}]`

### Проблема: "400 Неправильний запит — відсутні поля"
**Рішення:**
- Уважно прочитайте повідомлення про помилку
- Переконайтесь, що в тілі POST присутні всі три поля: email, address, cart
- Перевірте відсутність помилок у назвах полів

### Проблема: Помилки бази даних (500 Внутрішня помилка сервера)
**Рішення:**
- Перевірте, що файл бази даних існує або був ініціалізований
- Запустіть `python init_db.py` для ініціалізації БД
- Переконайтесь у правах доступу (файл мав бути для читання/запису)
