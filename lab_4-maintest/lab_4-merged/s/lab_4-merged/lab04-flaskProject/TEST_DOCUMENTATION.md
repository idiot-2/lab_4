# Тестова документація для вебзастосунку Flask

## Огляд тестів

Цей документ описує unit та integration тести для Flask вебзастосунку, розробленого в лабораторних роботах. Тести написані з використанням pytest та покривають критичні частини коду.

## Запуск тестів

Для запуску тестів використовуйте скрипт `run_tests.py`:

```bash
python run_tests.py
```

Або безпосередньо pytest:

```bash
pytest --cov=models --cov=routes --cov-report=html tests/
```

## Покриття коду

Тести забезпечують покриття критичних частин коду на рівні 50-70%. Звіт про покриття генерується в htmlcov/index.html.

## Структура тестів

- **tests/conftest.py**: Фікстури для тестів (app, client, runner).
- **tests/test_models.py**: Unit тести для функцій моделей.
- **tests/test_routes.py**: Integration тести для маршрутів та API.
- **run_tests.py**: Скрипт для автоматизованого запуску тестів з покриттям.
