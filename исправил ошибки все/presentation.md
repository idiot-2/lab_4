## Слайд 5: Технічна реалізація

### Backend (Flask):
- **Маршрутизація:** Blueprint для організації коду
- **База даних:** SQLite з міграціями
- **Безпека:** Хешування паролів, CSRF захист
- **API:** RESTful ендпоінти з Swagger документацією

### Frontend:
- **Шаблони:** Jinja2 з Tailwind CSS
- **Інтерактивність:** Vanilla JavaScript
- **UX/UI:** Інтуїтивний інтерфейс

### DevOps:
- **Контейнеризація:** Docker + Docker Compose
- **Тестування:** pytest (38 тестів)
- **CI/CD:** Готовий до розгортання

## Слайд 6: Система промокодів (нова функція)

### Можливості:
- Створення промокодів адміністраторами
- Процентні знижки (1-100%)
- Активація/деактивація кодів
- Застосування в кошику
- Автоматичний розрахунок вартості

### Технічна реалізація:
```python

# Застосування знижки
discounted_total, discount, error = apply_promo_discount(total, "NEWYEAR2026")
```
