# Магазин ігор на Flask

## Огляд проєкту

Це веб-додаток для інтернет-магазину ігор, розроблений на Flask. Проєкт включає повний функціонал електронної комерції з системою користувачів, кошиком, замовленнями та адміністраторською панеллю.

## Основні функції

### Для користувачів:
- Перегляд каталогу ігор з фільтрацією та пошуком
- Реєстрація та автентифікація
- Додавання товарів до кошика
- **Система промокодів** з процентними знижками
- Оформлення замовлень
- Перегляд особистого профілю

### Для адміністраторів:
- Управління товарами (створення, редагування, видалення)
- Управління замовленнями (перегляд, зміна статусу)
- **Управління промокодами** (створення, активація/деактивація)
- Перегляд повідомлень зворотного зв'язку

## Технічний стек

- **Backend:** Python 3.11, Flask
- **База даних:** SQLite
- **Фронтенд:** HTML, CSS (Tailwind CSS), JavaScript
- **API документація:** Swagger/OpenAPI (Flasgger)
- **Тестування:** pytest, pytest-flask
- **Контейнеризація:** Docker
- **Безпека:** Werkzeug (хешування паролів)

## Встановлення та запуск

### Локальний запуск

1. **Клонування репозиторію:**
   ```bash
   git clone <repository-url>
   cd flask-shop
   ```

2. **Створення віртуального середовища:**
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux/Mac:
   source .venv/bin/activate
   ```

3. **Встановлення залежностей:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Запуск додатку:**
   ```bash
   python app.py
   ```

5. **Доступ до додатку:**
   - Головна сторінка: http://localhost:5000
   - API документація: http://localhost:5000/apidocs
   - Адмін-панель: http://localhost:5000/admin

### Запуск через Docker

```bash
docker compose up --build
```

## API Endpoints

### Продукти
- `GET /api/v1/products` — отримання всіх продуктів
- `GET /api/v1/products/<id>` — отримання продукту за ID
- `POST /api/v1/products` — створення продукту

### Замовлення
- `GET /api/v1/orders` — отримання всіх замовлень
- `POST /api/v1/orders` — створення замовлення

### Системні
- `GET /health` — перевірка працездатності

## Система промокодів

### Створення промокодів
Адміністратори можуть створювати промокоди через адмін-панель:
- Код промокоду (унікальний)
- Процент знижки (1-100%)
- Статус (активний/неактивний)

### Використання промокодів
Користувачі вводять промокод у кошику для отримання знижки:
- Знижка застосовується до загальної вартості
- Один промокод на замовлення
- Автоматичний розрахунок фінальної ціни

## Розробка та тестування

### Налаштування середовища розробки
1. Встановіть Python 3.11+
2. Встановіть залежності: `pip install -r requirements.txt`
3. Запустіть додаток: `python app.py`
4. Для тестування: `python -m pytest tests/`

### Додавання нових функцій
1. Додайте маршрути у відповідний файл у `routes/`
2. Реалізуйте бізнес-логіку у `models.py`
3. Створіть шаблони у `templates/`
4. Напишіть тести у `tests/`

## Розгортання

### Production розгортання
Проєкт готовий до розгортання на таких платформах:
- **Heroku:** використовуйте `Procfile` та `requirements.txt`
- **Railway:** автоматичне розпізнавання Python додатку
- **Render:** вкажіть `python app.py` як команду запуску
- **Docker:** використовуйте `docker-compose.yml`

### Змінні середовища
```bash
FLASK_ENV=production
FLASK_APP=app.py
SECRET_KEY=your-secret-key
```
